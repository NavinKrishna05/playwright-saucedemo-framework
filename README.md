# Playwright SauceDemo Automation Framework

## Project Overview

This project is an automation framework developed using Playwright and JavaScript.

### Features
- Login Automation
- Add To Cart Validation
- Cart Validation
- Checkout Automation
- API Testing (GET & POST)

### Framework Design
- Page Object Model (POM)
- JSON Test Data
- beforeEach Hooks
- baseURL Configuration

### Tools Used
- Playwright
- JavaScript
- Git
- GitHub
- VS Code
